# Explore-the-World
Users can search for a city or country and view more information about each destination, including a description, popular attractions, images, and a special fact.

# How to run
1. Download the GitHub repository.
2. Open the project folder in VS Code.
3. Open index.html in the integrated browser.
4. The website will open in the integrated browser.

# Data source credits
The destination information is stored in destinations.json, a local JSON file created for this project.

The images used in the project are stored in the images folder.
